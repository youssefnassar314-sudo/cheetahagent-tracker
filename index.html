QUICK GUIDE

1. Pag-Login at Registration:
Kung bago ka pa lang, i-click ang "Register New Agent". Ilagay ang iyong email at i-confirm ang gagawing password. Kung may account ka na, ilagay lang ang iyong details sa Login screen at i-click ang "Access Systems".

2. Pag-add ng Target:
Kapag nakapasok na, piliin kung Residential o Business. Ilagay ang pangalan, area, at internet plan ng client. I-click ang "Add Target".

3. Paggamit ng Tracker:
Kapag nakabitan na ang client, i-click ang "Install". Lalabas ang date picker at ang "Copy Bill Info" button para madaling i-send sa Messenger ng client yung computation ng bill nila.

4. Ang FAB Menu:
I-click ang orange (+) button sa ibabang kanang bahagi para buksan ang mga extra tools: ID Generator, Calculator, Workspace, Area Locator, at Ledger.

Agent Operations Manual

Target Management
Add Target: I-save ang prospect details, area, at plan. Pwede ring i-tag kung sariling benta o hiniram.
Install: I-trigger ang billing computation at lalabas ang confetti kapag successful ang kabit!
Copy Billing Message: Auto-generated na ang message format para sa bill ng client na pwede mong i-paste agad sa Messenger.
Summary Board
Total Commission: Real-time computation ng potential income mo base sa mga Installed clients ngayong buwan.
Mini Stats: Mabilisang bilang ng iyong Pending, Installed, at Cancelled accounts.
Monthly Target: Visual tracker ng progress mo para ma-hit ang 20 installs na quota.
Agent Power Tools (FAB)
Area Locator: Searchable locations para i-verify kung covered ng fiber ang area ng client.
ID Generator: Gumagawa ng digital agent ID para mas legit tignan.
Prorated Calc and MBPS Estimator: Calculator tools para mas ma-assist ng maayos ang mga client
Workspace: Automatic na panggawa ng application forms (docx/pdf).
Ledger System
I-record dito ang iyong commissions/allowances/incentives kung magkano ang Kinita mo.
Account & Settings
Profile: Pwede mong i-set ang iyong Agent Name / Callsign na lalabas sa system.
Theme Switcher: Piliin ang kulay na swak sa mata mo (Dark Space o Sketch Theme).
Refresh Data: I-click ito para i-clear ang cache kung hindi nag-uupdate ang database.
